# Ratas de Borgonha — Official Archive

Primeira versão do catálogo para GitHub Pages.

## Álbum incluído

**Borgonha — First Album (Deluxe Edition)** — 8 faixas.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie `index.html`, a pasta `css`, a pasta `js` e este README.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Próximos passos

A estrutura pode ser expandida para várias eras e álbuns, mantendo cada álbum com sua própria tracklist e links do YouTube.
